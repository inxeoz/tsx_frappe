This represents your existing application (like Frappe). Notice how the styles here are completely separate from the dashboard below.

The IT Support Dashboard below is completely isolated and won't affect these styles.

IT Support Dashboard Integration

Integration Instructions

  1. Include the CSS: Add the built CSS file to your page
  2. Include the JS: Add the built JavaScript file to your page
  3. Create a container: Add a div with any ID you want
  4. Mount the component: Call the mount function

Example Integration Code:

<!-- 1. Include the built files -->
<link rel="stylesheet" href="/static_ui/main.css">
<script src="/static_ui/main.js"></script>

<!-- 2. Create container -->
<div id="my-dashboard-container" style="height: 600px;"></div>

<!-- 3. Mount the component -->
<script>
    // Wait for the script to load
    document.addEventListener('DOMContentLoaded', function() {
        const container = document.getElementById('my-dashboard-container');

        // Mount the React component
        // The mountReact function is exported from main.js
        if (typeof mountReact === 'function') {
            mountReact(container);
        }
    });
</script>

Frappe Integration Example:

# In your Frappe app's hooks.py
app_include_css = [
    "/assets/tsx_frappe/static_ui/main.css"
]

app_include_js = [
    "/assets/tsx_frappe/static_ui/main.js"
]

# In your Frappe page/doctype
frappe.ui.Page({
    title: "IT Support Dashboard",
    content: `
        <div id="it-support-root" style="height: calc(100vh - 150px);"></div>
        <script>
            if (typeof mountReact === 'function') {
                mountReact(document.getElementById('it-support-root'));
            }
        </script>
    `
});

Key Benefits of This Approach:

  • ✅ No CSS conflicts: All styles are scoped to .it-support-dashboard
  • ✅ No global pollution: CSS variables are contained within the component
  • ✅ Tailwind scoping: All Tailwind classes only apply within the component
  • ✅ Easy integration: Just include CSS/JS and call mountReact()
  • ✅ Isolation: Component is completely isolated from parent styles
  • ✅ Self-contained: No external dependencies on the parent application

Testing Integration Safety:

You can verify that the integration is safe by:

  • Checking that existing styles aren't affected
  • Ensuring the dashboard renders correctly in any container
  • Confirming that CSS variables don't leak outside the component
  • Testing that scrollbar styles only apply to the dashboard
